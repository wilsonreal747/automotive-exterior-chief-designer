# 预研阶段推进

先确认当前任务从哪个阶段开始。用[阶段交付表](references/design-gates.md)核对已有成果及接受范围。

| 当前输入 | 调用 | 取回的结果 |
| --- | --- | --- |
| 研究范围和设计命题 | automotive-gate1-insight | 行为证据和机会假设 |
| 已接受的机会与车辆边界 | automotive-gate2-experience | 场景分镜与实体状态证明 |
| 已选体验和比例边界 | automotive-gate3-direction | 体块、形态语法与关键视角 |
| 已选方向和已确认关键视角 | automotive-gate4-five-view | 成套视图与独立评审 |

跨阶段传递基准、工作图、确认状态和缺口。机制解释不清回到体验图，跨视角失真回到对应基准。若只委托一个阶段，到该阶段的工作图和决定即交付。
