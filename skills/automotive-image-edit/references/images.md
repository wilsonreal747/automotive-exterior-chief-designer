# 汽车生图：每次只比较能解释的变化

**先定基准。** 记录当前方案、输入图版本、视角、保护项、唯一变量和候选数量。锁定轮心、轴距读数、前后悬、车顶线、镜头、裁幅、姿态及项目明确冻结的区域。整车设计发展允许探索体量；单点改灯任务不能借此重做车身。

**选参考。** 优先已批准方案和能追溯来源的图库。学习叙事看完整项目；学习曲面反射、开口尺度或质感才用单张图。每张只承担明确角色：几何底图、特征供体、光影或环境。记录可借用的关系、不可复制的造型；参考授权与可否公开分开记录。

**组织任务。** 发散从同一干净底图分支，修错回到最近确认的干净版本；不要把前一张的缺陷传给整组。提示词例如：“把 @1 灯带由厚到薄的过渡用于 @2 的灯内；保留 @2 灯罩边界、车身、视角和轮位。”编号跟实际输入顺序一致。多张探索保持同一变量和相机；修错先做一张。按授权数量提交。

**局部修改。** 先叠看蒙版与原图是否同尺寸、选区是否包含接缝和必要过渡；生成后检查蒙版外是否变化、边缘是否断裂、反射是否沿原曲面连续。需要精确保护时核验输出像素，不能以提示词代替核验。

**画板。** 输入单列，每组一行，按相同显示宽度等比摆放，保留整车与间距。标清固定项、变量、判断。按画框实际边界、留白和标题位置检查，不以创建分区成功代替入框验证。不移动无关节点。服务端输出、已发布回画板、已下载是三种状态。保留任务与输出回执；超时先查已有结果，不自动重复付费。具体坐标、认证和参数以工具正本为准。

**筛选顺序。** 缩略图看轮廓和重心；同尺度叠对轮心、温室及前后悬；全尺寸看灯具分件、熄灯状态、开闭线、密封路径、材质接缝。再判断是否命中本轮变量及车格。高级感要能指出来自哪段曲面、哪个比例或哪组材质关系；装饰发光不证明智能功能。无法核对的硬点标“未核”，不要推断合规。

交付候选对照：输入版本｜视角｜变化｜通过/淘汰理由｜下一步。只把选中候选移入正式版本索引，失败尝试留在工作区。
