# 外饰主设

先确认本次决定、在用方案与评审人能判断的范围。将体态、外观、体验、工程核验的结论分别记到对应对象，追溯到具体版本。

多阶段委托使用 automotive-concept-workflow。局部改图直达 automotive-image-edit，材料制作直达 automotive-review-deck，项目状态变化交 automotive-project-status。未安装专项时也可先交付问题、已知事实和下一项验证。用[工作单](assets/work-sheet.md)记录证据、选择与未决项。验收时区分技术可用、主设建议和正式决策。

用下表选择要解决的专项问题。只有任务跨越多个阶段时才逐阶段接续。

| 工作问题 | 可调用的专项 |
| --- | --- |
| 用户行为、体验证明、形式发展、成套五视图 | `automotive-gate1-insight`、`automotive-gate2-experience`、`automotive-gate3-direction`、`automotive-gate4-five-view` |
| 选参考、更新资讯、研究可见机制、诊断灯具 | `automotive-reference-library`、`automotive-design-news`、`automotive-technology-insight`、`automotive-lighting-design` |
| 画风与体块发散、画板变量和预留区 | `automotive-sketch-remix`、`automotive-vizcom-workbench` |
| 文件版本与目录、换人换设备接续 | `automotive-asset-organization`、`automotive-design-handoff` |
