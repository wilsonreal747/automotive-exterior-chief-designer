# 设计参考库

先查设计师评过的原图和已有索引，再补外部来源。核对实际图像、作者、原始出处、使用权和评价对象。用画面具体特征写检索词，例如“侧窗下沿直切面，后端内收”。

单张供体记录可借用的关系和排除项；学习叙事时保留项目图序与每一步解决的问题。交付带缩略图或来源指针的选图表，把作者事实、设计师意见和助理解释单列。用文件哈希或稳定来源去重，图库引用可跨方案复用。

视频参考先记原片、作者、时间码、评价和可迁移方法，按表达任务检索。需要逐镜、节奏与声音拆解时调用 automotive-video-director；参考库保留轻量索引，原片和项目工程存文件层。不将用户评价和助理解读混为一谈。
