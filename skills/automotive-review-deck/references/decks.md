# 评审 PPT：从决策反推页面

先找当前使用的母版与正式素材批次，明确听众、时长和这次能做的决定。技术预审讲接口、约束和风险；方向选择讲同尺度的差异和取舍；对外展示讲用户能感知的结果。保留已接受的叙事与手改内容，只改影响决定的部分。

**逐页先写五栏：** 页目的｜主图与来源｜观众看见的一句话｜讲者补充｜内部待核。每页一个判断、一个主视觉。别把带旧标题的整页截图当背景；从获准使用的母资产提取干净图层。整车不拉伸，细节图交代它在车身的位置。图、结论、备注分层；讲稿与来源进备注，机密内容即使在备注也不能随公开版本分发。

| 页面任务 | 推荐画面 | 这一页能决定什么 |
| --- | --- | --- |
| 提出问题 | 场景切片或动作序列 | 这个摩擦值得解决吗？ |
| 证明体验 | 英雄图配状态/断面，看到手、物、开口的关系 | 机制可信，还是先做样件？ |
| 比较方案 | 同角度同尺度并排，控制背景与照明 | 保留哪个方向、放弃什么？ |
| 收口 | 推荐方向、关键未决项和下一步验证 | 批准深化、要求修订，还是暂停？ |

要“加强创新点”，就补能说明动作的图、用例链、可比案例或工程边界；不在旧图上贴个新标签交差。成本写估算范围、假设和排除项；无供应商数据勿冒充报价。

**交付两道检查。** 技术：保存工作副本，逐页导出，检查字体替换、标题断行、越界、图片裁切、备注和可编辑性。优先目标 PowerPoint 原生渲染；没做原生检查就说明实际用的渲染器。设计：整车完整，车格/尺度正确；开闭件可运动；构图能看清要决定的差异。任何一项不能因文件可打开而自动通过。最终保留母版、交付版、逐页预览和待核项。

可复制示例见 [可编辑评审样板](../assets/review-starter.pptx)。它是用于替换内容的虚构提案，不是获批方案。
