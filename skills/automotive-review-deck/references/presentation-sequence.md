# 把设计工作图编成演讲

先写完整论证，再选图，再排页。已有材料优先读取当前基准、逐页大纲、图片索引和评审意见。修一处批注先定位到具体对象，再检查修改是否影响跨页论证。语义相同的重复页可合并，页数随听众需要决定。

| 讲到哪一步 | 在排版前备好的图 | 观众能回答的问题 |
| --- | --- | --- |
| 谁遇到了什么 | 可溯源的生活行为切片、口径一致的市场比较 | 谁在何时遇到这个问题，证据来自哪里？ |
| 体验怎样发生 | 远景交代处境，中景看动作，特写看手、物和外饰界面，结尾看动作结果 | 哪个部件在什么时候帮到了人？ |
| 体验怎样成为造型 | 一张空间或氛围意向、一张能看懂接缝或开口的产品意向、一张本方案的断面或体块 | 借了哪一种关系，它落在车的哪里？ |
| 为何选这个方向 | 同镜头、同尺度的方案，配一处能辨出差异的局部 | 选了什么，付出的代价是什么？ |
| 还要验证什么 | 开合轨迹、断面、样件或未决界面 | 哪项结果会改变今天的选择？ |

**故事板。** 用同一人物、道具和车辆连续讲一个事件。先定每幅的动作和景别，转折处给更大画面，格间留呼吸。四个相似的车外镜头很难交代人何时换手、物件怎么越过门槛。生成插画标注“体验提案”，真实观察保留出处。

**视觉页。** 现场支持宽幅时可用约 2.35∶1 的画面。建筑讲尺度、边界和光，接一张产品特写讲壳体、切口或装配，再用自己的工作图证明转译。让大图铺到画边，裁切保住关系；单幅、对开、三联和无标题图页交替。比较页保留同尺度。中文细体可选 HarmonyOS Sans SC Thin 或 Light，短英文标题可用 Bodoni MT Condensed 或细长无衬线配适量字距。先试投影可读性，留一种强调色，每页一条口头能说完的判断。

**数据与交付。** 核对图例、车型类别、坐标单位、统计周期与气泡大小含义。以原生表格或可编辑矢量重绘，保留源数据。提取可使用的原图，再按新画幅裁切。把技术依据置于备注或附录，公开副本另查备注、隐藏页、批注、外链和嵌入文件。导出整套并逐页看一次，在实际演讲设备或目标播放器核对字体、对比图尺度和长标题换行。
