# 外饰评审 PPT

从当前母版、听众、评审决定和可用原图开始。先整理论证，再准备图片清单，再排页。按[叙事序列](references/presentation-sequence.md)决定哪些页讲证据、动作、造型关系和选择；制作与验收见[评审 SOP](references/decks.md)。

可替换的[四页 PowerPoint 样板](assets/review-starter.pptx)随技能安装。目标播放器导出逐页检查，并记录字体、裁切、比较尺度和可编辑性。已有母版时优先沿用已确认的图与手改页面。
