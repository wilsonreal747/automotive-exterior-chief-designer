# 按产物调度技能

## Vizcom 视频补镜与参考运动

需要用本地短片和车型图片生成镜头时，调用 [Vizcom 视频 MCP 与 Skill](https://github.com/wilsonreal747/vizcom-mcp/blob/main/docs/ANIMATE.md)。先上传 H.264 MP4、导入图片，再把返回的素材 ID 接入 Animate；按镜头任务明确画幅、Fast/Pro、音频开关和时长。现有节点通过 update_animate 修改并回读，不用重新建节点代替参数修改。生成另行提交，保存 outputId，查询同一任务后下载 MP4；超时不重复付费。

工具接受非分片单视频轨 MP4，最大 256 MiB、30 秒、单边 4096 像素，不自动转码。Fast 5–15 秒，Pro 4–15 秒；Fast 音频的界面描述与实测存在差异，必须检查文件音轨。镜头是否成立仍由导演审查；四项参数写入、文件可解码、设计保真分别验收。缺工具时报告当前宿主未加载，不接管窗口。

这些名称是可发现的候选能力，不代表所有设备都已安装、具备授权或完成实测。执行前枚举宿主技能并读取所选 SKILL.md，核输入、工具、许可与实际版本。表中的外部技能不随本包分发；缺失时用同类能力或交付可执行方案，不自动安装、购买或上传素材。

## 调用顺序与交接

1. 先选表达和素材，不先选渲染器。纯实拍裁切用现有编辑器；只有需要程序化字幕/蒙版/动效时才加载相应引擎。
2. 使用一个简短交接包：任务、输入文件或来源 ID、可改与不可改、时间段、目标产物、验收条件。工具缺失要返回缺什么和已完成什么。
3. 接收结果后由导演核镜头和音画，由主设核设计证据。工具输出成功不等于影片成立。失败保留原工程和日志，从失败环节恢复，不重做已合格素材。
4. 不需要全部技能都调用。尊重用户选择与原工程体系，不因工具默认值改变画幅、添加配音或套用语音剪辑规则到无对白的汽车片。
