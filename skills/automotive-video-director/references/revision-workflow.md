# 外饰影片迭代：锁定设计，重做镜头

用于已有分镜、参考片或可编辑时间线的外饰影片改版。不是用 AI 替代导演判断，也不是把效果更“炫”的版本自动替进片子。现成镜头合格就保留。

## 1. 锁定基线，写清镜头在讲什么

从最近**实际交付**的时间线分支，保留上版及原始素材。镜头表每行记镜头 ID、用途、源文件与入出点、目标帧区间、进出镜头的衔接动机、当前车色/场景/光线、不可变项、允许改变的变量、验收状态。用户指定的图和镜头 ID 不凭文件名猜；抽取幻灯片源图并比对当前版本，检查叠放、出画布或被裁切的备选图。页上顺序以实际确认的分镜为准，不按媒体文件名编号重排。

先标叙事分界：在哪由室外进入室内，在哪切换车色或车格，什么可见动作完成切换。把色温、空间和光向按段检查，不在中间随意穿插。室内连续几条都只表达“正在交谈”时，留最能交代空间或推动转场的内容，例如一个建立镜头和一个手举杯。为锚点腾出的时长留给有独立信息的镜头，不拉长空镜或堆同义素材。

## 2. 一张参考只负责一件事

| 约束 | 应使用的输入 | 不得顺带复制 |
| --- | --- | --- |
| 构图与氛围 | 审定分镜源图或当前有效首帧 | 错误灯具、临时车模的比例 |
| 车型身份与细节 | 当前整车四分之三视角，加近角度灯具/轮毂局部 | 局部图自身的镜头、给参照用的车漆和色温 |
| 运动 | 边界明确的高质量实拍段，记录原片时间码与可迁移的视差、车势和节奏 | 他车灯型、车标、剪点或参考片中的缺陷 |

先把缺陷变成可看见的验收条件，再写生成指令。分开写首帧、哪个对象动、相机如何动、什么必须不动，以及禁止误带入的特征。优先真实运动底片换车型的镜头：双车要先核相对前后、车道与遮挡，再核两辆各自身份；同一段里姿态或天气不对，就换底片，不靠提示词补一个不可见动作。无合适运动底片时用设计静帧生成或用准确绑定的模型校验运动，再择片。已经达到画质且叙事合格的空镜、实拍不重生成。

调用 [能力调度](skill-orchestration.md) 中的 Vizcom 工作流：给参考图和视频分工，按画板真实能力提交，保留任务、节点与结果 ID。模型没有遵守约束时先减少互相冲突的参考、分别验证设计和运动；超时或状态不明先读回，不盲目重提。同一项目有知识产权、上传与预算边界时沿用其授权；未获授权的参考片不作为公开交付素材。

## 3. 看懂“动了什么”，不只看有无运动

- **灯具：** 先核外轮廓的宽高与它占车身的比例，再核点亮层级。连续灯形（例如 L）在运动前后都要连续，非发光饰条不能被点亮；表面扫光不等于光源变形或被重新排布。
- **轮毂：** 停车时用短滑轨、微弧或变视差表现轮拱、内外口和中心盖的关系；整帧放大只能模拟推近，不证明有真实运镜。行驶时轮胎和轮毂同轴同速滚动；转向是另一轴向。轮毂相对胎壁独自旋转、轮心抖动、饰盖漂移或开孔时有时无，一律退回。
- **车与环境：** 相机跟车要能从地面和远景的相对位移读到速度，烟雾运动不能代替车的运动。细节仍要在镜头长度内看清。动物或人物以原图的构图、形态及方向为准，仅让完整的动作在画内成立，不为露全身而擅改相机。
- **实看片段：** 先看文字档快速审每个镜头要做什么；改动镜头看首、中、尾和原速连续播放，并看前后相邻镜头。只有做精确复刻或处理明确伪影才逐帧。设计准确、动作可信、叙事正确三者分开判定，不能用其中一项抵销另一项。

## 4. 音乐锚点与交付回归

先听完整原曲，在**源音频**记结构切换、动作声和落版落点，并换算到成片时间线。固定音乐和锚点后改画面分配；切点本身和前后镜头的因果都要成立。用同一首连续原曲时不为凑时长擅插别曲。结尾从最后一个有效画面走到落版和音乐收束，检查停留时长与尾音，不能靠突然切黑结束。

改版导出前回读镜头 ID、帧段、无缝覆盖、保护项、素材路径及连续音轨。音乐不动时可比对导出音轨与基线，改的是剪点就复听关键点。可编辑工程关闭重开查素材链接，给带镜头编号的完整审片，不用生成的短样冒充整片。合格改动才替入；仍不合格就明确指出哪个镜头保留上版。按[视听验收](film-qa.md)报告技术检查、实际视听检查和设计审批各自结果。

## 快速试用

- **正例：** 黑漆尾灯要换另一张分镜视角并保持同一室外夜景。先比两张原图与上版；以另一张图管机位，以量产或已批准局部管灯轮廓与发光层级，若运动来自实拍只迁移相机与环境视差。检查转入室内仍在既定位置。
- **反例：** 只做一个镜头的灯型修正，其他镜头与音乐均已批准。只改该镜头并检查邻接与画幅，不重新生成整片、不重排叙事、不挪音乐。
