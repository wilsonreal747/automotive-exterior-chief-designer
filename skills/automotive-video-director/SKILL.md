# 汽车视频导演

本技能属于外饰主设技能集，可独立完成汽车影片方案与参考拆解。主设判断设计意图和车型基准，本技能把意图转为镜头与声音。通用剪辑、生成、渲染由现有工具完成，不在这里复制工具手册。

## 从任务进入

- **找对标、拉片：** 读 [对标与拆解](references/benchmark-and-breakdown.md)，交付原片证据、时间码和可迁移方法；不自动开始拍摄或剪辑。
- **做片、改片：** 采用已有目标、素材和反馈；先确定影片命题与缺口。已有时间线或已审分镜的迭代，读[锁定设计与改片 SOP](references/revision-workflow.md)，用镜头 ID、设计基准和音画锚点做回归。
- **评片：** 先实际观看和听审，指出具体时间段、表达问题及替换动作，不用“更高级”代替修改建议。

## 工作流程

1. **定表达。** 一句影片命题，列出必须看清的设计或体验证据，确认受众、用途、画幅、时长弹性、在用车型版本与可用素材。已有信息直接采用。
2. **选对标。** 先检索用户评过的多媒介参考，再补品牌、导演与制作团队原片。按表达任务而非热度选择，用 [对标工作单](assets/film-work-sheet.md)记录取舍。
3. **拆成方法。** 对关键段落逐镜核时间码、景别、机位、运动、光影、动作、音效与切点，再推导它为何有效。区分实际所见、测量值和解释；无原片或未听审时不写完整拉片结论。
4. **转成自己的片。** 写出“借用的关系 → 本车证据 → 镜头组 → 素材或补拍需求”。完整比例、姿态、关键面、灯具和细节各有位置。缺素材优先缩短、补拍或补授权镜头，不拿竞品冒充本车。
5. **制作。** 读 [能力调度](references/skill-orchestration.md)，只加载本轮所需技能。实听音乐与动作声后建立情绪段落，先用少量镜头验证表达，再展开剪辑、调色、字幕蒙版和动效。
6. **审片。** 用 [视听验收](references/film-qa.md)检查设计保真、镜头关系、音乐情绪和导出。返回带时间码的缺陷与处理结果，区分文件可解码、实际观片通过和设计师接受。

## 表达判断

| 任务 | 应让观众看到 | 常见误区 |
| --- | --- | --- |
| 外饰评审 | 完整比例与姿态、关键面关系、灯具与细节、变化前后 | 快闪、暗光和遮挡掩盖设计问题 |
| 性能驾驶 | 操作、车辆响应、道路空间及动作结果 | 全片等速快切，只有车轮与转速表，靠变速证明性能 |
| 豪华品牌 | 环境命题、体验、精工材质与整车的关系 | 把慢放、金字、黑底或大面积光效等同高级 |
| 硬派越野 | 地形挑战、接地和悬挂响应、通过动作及远景轨迹 | 只有扬尘、抖镜和航拍，缺乏真实机械响应 |

## 交付与归档

交付选定对标、拆解结论、镜头方案或可编辑工程、审片文件、已验收范围与剩余问题。短任务按需要裁剪，不为填表增加工作。

参考库轻量保存来源、评语、用途、时间码和媒体路径；素材与工程保留在项目文件层。用户评价、作者事实与助理解读分别记录。私人项目名称、未公开车型、账号及私有资料不进入公开技能；生成或上传之前沿项目授权边界选择工具。参考学习不等于取得素材再利用许可。
