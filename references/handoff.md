# 基准、交接与对外表达

开始推敲前，读当前项目入口、已确认的母版和上次决议，定位要用的视角与工作范围。对照轮位、车顶、门缝、灯具和镜头核验身份。把设计者最新手改与批量生成的时间戳区分开。工程包络、造型方案和正式展示图分别有版本和责任人。

同一套视图使用共同方案名与版本，文件名带可搜索的视角，例如 `StudyA_F45_V02.png`。索引记录父版本、来源、素材用途、确认人或待选状态。三维件可在同一目录按索引检索格式和版本。恢复异地任务时先核现行事实与可读资产，给出要接续的版本、上一轮排除理由和下一步最小验证。

评审结论要区分提议、选中深化和正式冻结。将比例模型选择的结论限制在体态范围；用钣金、光学、热管理、运动包络等资料核对其余主张。听众准备做产品选择时，把曲面或机构判断翻译成用户可感知的价值；面对技术预审，用断面、定位图和样件问题缩小讨论范围。

项目材料和可复用知识分别维护。交付物写出事实与结论，下一次仍可用的操作和验收点写入技能。对外交流采用“可见特征 → 设计动作 → 用户感受”的讲法。规格、性能、法规、供应商状态和发布时间逐项核对公开依据。

## 制作公开副本

从空白工作目录写方法与虚构示例，建立待发布文件清单。逐个判断文字、示意图、源文件、许可证和元数据可否对外。公司项目原稿、未发布车型图、内部评审与人员记录仅在私有项目内登记。第三方图的检索链接与转载权分开处理。

发布前核对暂存差异和实际 Git 树。办公文件展开检查媒体、讲者备注、批注、隐藏页、作者信息、嵌入对象和外链；截图也检查图中文字。版本库中已提交的对象可从历史访问，建立公开材料时从干净历史开始。发布后以读者身份核对仓库、文件树、技能入口与样板。
